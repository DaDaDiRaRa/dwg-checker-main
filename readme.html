도면목록표 ↔ 개별 캐드 도면 자동 교차 검토  |  개발: 김정현 (junghyunk9966@gmail.com)

프로그램 소개 사전 준비 ROI 설정 프로그램 실행 리포트 읽기 동 추출 방식 FAQ 버전 히스토리

💡 프로그램 소개

실시설계 도서 납품 전, '도면목록표'와 수백 장의 개별 캐드 도면(DWG) 정보를 자동으로 교차 검토하는 QA 자동화 솔루션입니다.
사람의 눈으로 찾기 힘든 도면 누락, 오타, 도면번호 불일치, 축척(A1/A3) 오류를 단 몇 분 만에 컬러 엑셀 리포트로 출력합니다.

검토 흐름 한눈에 보기

도면목록표 DWG + 개별 도면 폴더(들) → 컬러 엑셀 리포트

리포트에 담기는 항목

열 이름내용
도면번호AA-000-000 형식의 도면번호
구분(동/구역)동 및 구역 정보 (예: 102동, 102동 코어#1)
도면명도면 제목
축척_A1A1 용지 기준 축척
축척_A3A3 용지 기준 축척

각 항목은 도면목록표(LIST)와 개별 도면(DWG) 양쪽에서 추출되어 대조됩니다.

🛠️ 필수 사전 준비 (처음 1회만)

1
ODA File Converter 설치

프로그램이 DWG 파일을 내부적으로 읽기 위해 반드시 필요한 변환 엔진입니다. 프로그램 최초 실행 시 자동으로 설치 안내가 표시됩니다.

⚠️
설치할 때 기본 경로(C:\Program Files\ODA)를 변경하지 마세요. 경로가 바뀌면 프로그램이 엔진을 찾지 못합니다.

다운로드: https://www.opendesign.com/guestfiles/oda_file_converter (무료)

2
SET_ROI.lsp — AutoCAD 구역 설정 도구

프로그램이 캐드 도면의 어느 위치에서 도면번호·도면명·축척을 읽어야 할지 좌표 정보를 저장하는 도구입니다. 오토캐드에서 딱 한 번만 실행하면 됩니다.

✅
V6.8 신기능 — 자동 추출
DWGChecker.exe를 처음 실행하면 SET_ROI.lsp 파일이 EXE와 같은 폴더에 자동으로 생성됩니다. 별도로 파일을 준비할 필요가 없습니다.

AutoCAD LT 사용자 주의: LT 버전은 LISP 명령을 지원하지 않습니다. SET_ROI.lsp 실행에는 AutoCAD 정식 버전(Full)이 필요합니다.

📍 Step 1 — 오토캐드에서 구역(ROI) 설정하기

ROI(Region of Interest)란 프로그램이 캐드 도면에서 읽어야 할 위치(도면번호, 도면명 등)를 미리 알려주는 좌표 정보입니다.
프로젝트 도곽이 바뀔 때마다 최초 1회만 설정하면 됩니다. 설정 값은 컴퓨터에 자동 저장됩니다.

ℹ️
ROI는 도곽 블록 이름별로 저장됩니다(%APPDATA%\AutoDWG_Checker\블록명.json). 같은 도곽을 쓰는 프로젝트라면 한 번 설정 후 계속 재사용할 수 있습니다.

실행 방법

  • 오토캐드 명령어 창에 SET_ROI를 입력하고 Enter
    LISP를 먼저 로드해야 합니다. SET_ROI.lsp 파일을 오토캐드 화면에 드래그 앤 드롭하여 로드하세요.
  • 도곽 블록(또는 외부참조) 클릭
    도곽의 블록 삽입점을 클릭하세요. 이 블록 이름이 프로그램에서 사용할 '도곽 블록 이름'이 됩니다.
  • 개별 도면 구역 3곳을 순서대로 드래그하여 지정
①
도면번호 구역 — 도면번호(예: AA-300-001)가 적힌 칸을 드래그해서 박스로 지정합니다.
②
도면명 구역 — 도면 제목이 적힌 칸을 드래그합니다.
③
축척(SCALE) 구역 — A1/A3 축척이 적힌 칸을 드래그합니다.

④ 뷰심볼 탐색 영역 (선택 사항)

도면 내부에 원+선 형태의 뷰 기호(상세도 참조 심볼)가 있다면 해당 심볼들이 모여 있는 영역 전체를 드래그하여 지정하세요.
지정하면 리포트에 시트 2(뷰심볼 검토)가 추가로 생성됩니다. 이 검토가 필요 없다면 Enter를 눌러 건너뜁니다.

⑤ 도면목록표 단(Column) 지정

도면목록표에서 데이터가 나열된 '단(세로 열)' 전체를 위에서 아래로 드래그하여 지정합니다. 여러 단이 있는 경우 왼쪽 단부터 오른쪽 순으로 반복 지정하고, 모든 단 지정이 끝나면 빈 공간에서 우클릭(또는 Enter)으로 완료합니다.

🚀 Step 2 — 자동 검토 프로그램 실행

  • DWGChecker.exe 더블클릭으로 실행
    처음 실행 시 ODA File Converter가 설치되어 있지 않으면 설치 안내 창이 자동으로 뜹니다.
  • 아래 4가지 항목을 순서대로 입력합니다.
① 도곽 원본
도곽으로 사용된 원본 파일(예: X-FORM.dwg)을 선택하거나 창에 드래그 앤 드롭하세요.
파일을 드롭하면 도곽 블록 이름이 자동으로 채워집니다. XREF가 없는 경우 직접 타이핑해도 됩니다.
② 도면목록표
표지 쪽에 있는 도면목록표 DWG 파일을 선택하거나 드롭하세요.
③ 개별 도면 폴더
검토할 개별 도면들이 모여있는 폴더를 추가합니다.
폴더를 창에 드래그하거나 [+ 폴더 추가] 버튼으로 추가하세요. 여러 폴더를 한 번에 드롭하는 것도 가능합니다.
④ 고급 옵션
개별 도면의 도곽 블록 이름이 도면목록표와 다를 경우에만 체크박스를 켜고 별도 이름을 입력합니다.
좌표(ROI)는 항상 도면목록표 도곽(Master)을 기준으로 적용됩니다.
  • [검토 시작 →] 버튼 클릭
    하단 진행 바와 로그 콘솔에서 진행 상황을 실시간으로 확인할 수 있습니다. 수십 초 ~ 수 분 소요됩니다(도면 수에 따라 달라집니다).
  • 분석 완료 후 리포트가 있는 폴더가 자동으로 열립니다.
    작업 중 취소가 필요하면 [⏹ 취소] 버튼을 누르세요. 완료된 분량까지 리포트가 저장됩니다.
✅
V6.8 신기능 — 타임스탬프 파일명
리포트는 도면검토리포트_20260608_143022.xlsx 처럼 날짜와 시각이 붙은 이름으로 저장됩니다. 실행할 때마다 새 파일이 만들어지므로 이전 리포트를 덮어쓸 걱정이 없습니다.

📋 시트 1 — 목록표 검토 (메인 시트)

도면목록표(LIST)와 개별 캐드 도면(DWG)을 도면번호 기준으로 대조합니다. 불일치 항목의 해당 셀이 빨간색으로 강조됩니다.

상태의미
일치양쪽 모든 항목이 정확히 일치하는 정상 데이터
DWG 누락도면목록표에는 있으나 해당 CAD 파일이 존재하지 않음
목록표 누락CAD 파일은 있으나 도면목록표에 없는 도면
도면번호 불일치목록표와 DWG의 도면번호가 서로 다름
도면명 불일치도면 제목이 서로 다름 (오타, 줄임말 등)
축척 불일치A1 또는 A3 축척 값이 서로 다름
동 불일치동·구역 정보가 서로 다름
도면명/축척 불일치여러 항목이 동시에 다를 경우 /로 항목을 연결하여 표시

🔍 시트 2 — 뷰심볼 검토

각 CAD 도면 내부에서 원+선 형태 뷰 기호(부분 상세도 참조 심볼)를 감지하여 도곽에 표기된 도면명·축척과 일치하는지 검토합니다.
ROI 설정 시 뷰심볼 영역을 지정했을 때만 이 시트가 생성됩니다.

상태의미
일치뷰심볼의 도면명과 축척이 도곽 정보와 모두 일치
도면명 불일치뷰심볼에 적힌 도면명이 도곽 도면명과 다름
축척 불일치뷰심볼에 적힌 축척이 도곽 축척과 다름
도면명/축척 불일치도면명과 축척 모두 다름
중복같은 파일 내에 동일한 뷰 도면명이 2개 이상 존재 (오타 의심)

🏗️ 동(구역) 정보 자동 추출 방식

도면목록표에서 동·구역 정보(구분 열)를 자동으로 분리하는 규칙입니다.

① 도면명 앞에 동 이름이 있는 경우

도면명 맨 앞에 102동, A동 같은 동 식별자가 있으면 별도 열로 분리합니다.

102동 지하6층 평면도 → 동: 102동 / 도면명: 지하6층 평면도

② 동 뒤에 세부 구역(코어 등)이 있는 경우

층 정보(지하N층, 지상N층) 앞에 오는 구역 식별자를 동 정보에 합산합니다.

102동 코어#1 지하6층 평면도 → 동: 102동 코어#1 / 도면명: 지하6층 평면도

③ 들여쓰기 상속

도면목록표에서 공통 동·구역 정보가 생략된 들여쓰기 행은 위 행의 동 정보를 자동 상속합니다.

AA-300-081 102동 지하6층 평면도 → 동: 102동 AA-300-082 (들여쓰기) 지하5층 평면도 → 동: 102동 ← 자동 상속 AA-300-083 (들여쓰기) 지하4층 평면도 → 동: 102동 ← 자동 상속 AA-400-001 101동 코어#1 지하6층 평면도 → 동: 101동 코어#1 AA-400-002 (들여쓰기) 지하4층 평면도 → 동: 101동 코어#1 ← 자동 상속

❓ 자주 묻는 질문 (FAQ)

리포트 파일이 어디에 저장되나요?
DWGChecker.exe가 있는 폴더에 자동 저장됩니다. 분석이 끝나면 해당 폴더가 탐색기에서 자동으로 열립니다.
파일명은 도면검토리포트_20260608_143022.xlsx 처럼 날짜_시각 형식이라 실행할 때마다 새 파일이 생깁니다.
"구역 설정(JSON) 파일이 없습니다"라고 뜹니다.
입력한 '도곽 블록 이름'과 SET_ROI로 저장했던 도곽 이름이 다를 때 발생합니다. 띄어쓰기, 대소문자, 언더스코어 유무까지 정확히 일치해야 합니다. 오토캐드에서 도곽 블록을 클릭하고 속성창에서 정확한 이름을 확인하세요.
도면번호나 축척이 이상하게 추출됩니다.
오토캐드에서 SET_ROI를 다시 실행하여 구역 박스를 조금 더 넓게(또는 타이트하게) 조정해 보세요. 박스가 해당 텍스트를 제대로 포함하고 있는지 확인합니다.
개별 도면과 도면목록표의 도곽 블록 이름이 다릅니다.
프로그램 창의 고급 옵션 체크박스를 켜고 개별 도면에서 사용하는 도곽 블록 이름을 별도로 입력하세요. ROI 좌표는 항상 도면목록표 도곽(Master)을 기준으로 적용됩니다.
뷰심볼 검토 시트 2가 생성되지 않습니다.
SET_ROI 실행 중 뷰심볼 탐색 영역 지정 단계에서 Enter만 눌러 건너뛴 경우 시트 2가 생성되지 않습니다. SET_ROI를 다시 실행하여 뷰심볼이 배치된 영역을 드래그로 지정해 주세요.
한글 폴더명(예: C:\도면파일\)에 있는 DWG를 분석하면 오류가 납니다.
V6.8부터 자동 해결됩니다. 한글이 포함된 경로의 DWG 파일은 내부적으로 ASCII 임시 경로에 복사된 후 분석됩니다. 별도 조치가 필요 없습니다.
동 정보가 도면명에 붙어서 분리되지 않습니다.
동 이름이 도면명 맨 앞(첫 토큰)에 있어야 분리됩니다. 중간이나 끝에 있는 경우에는 도면명의 일부로 처리됩니다. 도면목록표 원본 작성 규칙을 확인해 주세요.
분석이 너무 느립니다.
프로그램은 최대 4개의 CPU 코어를 동시에 사용하여 도면을 병렬 처리합니다. 도면 수가 많거나 파일 크기가 클수록 시간이 더 걸리는 것은 정상입니다. ODA File Converter를 통한 DWG→DXF 변환 자체가 일정 시간을 소비합니다.
도곽이 회전되어 있는 경우에도 인식되나요?
네. 90°, 270° 회전된 도곽도 자동으로 보정하여 올바르게 분석됩니다. 일반 INSERT 블록과 외부참조(XREF) 도곽 모두 지원합니다.
AutoCAD LT에서도 SET_ROI를 쓸 수 있나요?
아니오. AutoCAD LT는 LISP(.lsp) 명령을 지원하지 않습니다. SET_ROI.lsp 실행에는 AutoCAD 정식 버전(Full)이 필요합니다. 단, ROI를 이미 다른 컴퓨터(Full 버전)에서 설정한 후 %APPDATA%\AutoDWG_Checker\ 폴더의 JSON 파일을 복사해 사용하는 것은 가능합니다.
여러 프로젝트의 ROI 설정을 팀원과 공유할 수 있나요?
%APPDATA%\AutoDWG_Checker\ 폴더에 있는 블록명.json 파일을 그대로 복사해서 전달하면 됩니다. 받은 사람이 같은 경로에 붙여넣으면 ROI 재설정 없이 바로 사용 가능합니다.
