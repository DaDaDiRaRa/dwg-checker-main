AutoDWG 도면 검토 자동화 시스템

도면목록표 ↔ 개별 캐드 도면 자동 교차 검토  |  개발: 김정현

프로그램 소개 사전 준비 사용 방법 리포트 읽기 동 추출 방식 FAQ 버전 히스토리

💡 프로그램 소개

실시설계 도서 납품 전, '도면목록표'와 수백 장의 '개별 캐드 도면' 정보를 자동으로 교차 검토하는 업무 자동화(QA) 솔루션입니다.
사람의 눈으로 찾기 힘든 데이터 누락, 오타, 도면번호 불일치, 축척(A1/A3) 오류를 단 몇 분 만에 엑셀 리포트로 출력합니다.

추출 항목내용
도면번호(LIST)AA-000-000 형식의 도면번호
구분_LIST(동)동 및 구역 정보 (예: 102동, 102동 코어#1)
도면명(LIST)도면 제목
축척_A1(LIST)A1 용지 기준 축척
축척_A3(LIST)A3 용지 기준 축척

🛠️ 필수 사전 준비 (처음 1회만)

1
ODA File Converter 설치

프로그램이 DWG 파일을 내부적으로 읽기 위해 반드시 필요한 변환 엔진입니다.

⚠️ 설치 경로를 C:\Program Files\ODA 기본값 그대로 유지하세요. 경로를 변경하면 프로그램이 엔진을 자동으로 찾지 못합니다.

다운로드: opendesign.com → ODA File Converter에서 Windows 버전 설치

2
AutoCAD에서 SET_ROI LISP 로드

배포 폴더의 SET_ROI.lsp 파일을 오토캐드 화면에 드래그 앤 드롭하여 로드합니다.

ℹ️ 이 LISP는 Python이 도면의 어느 위치를 읽어야 하는지 좌표(ROI)를 알려주는 역할입니다. 설정 데이터는 %APPDATA%\AutoDWG_Checker\에 자동 저장됩니다.

🚀 사용 방법 (Step-by-Step)

Step 1  ·  AutoCAD에서 도곽 구역(ROI) 설정

프로젝트 도곽이 바뀔 때마다 최초 1회만 실행하면 됩니다.

  1. 오토캐드 명령어 창에 SET_ROI를 입력하고 엔터를 칩니다.
  2. 현재 도면에 있는 도곽 블록(또는 외부참조)을 클릭합니다.
  3. 안내에 따라 [도면번호], [도면명], [축척(SCALE)] 텍스트가 들어가는 구역을 각각 드래그하여 박스로 지정합니다.
  4. [뷰 심볼(원+선) 탐색 영역]을 드래그하여 지정합니다. 도면 내부의 원+선 형태 제목 기호들이 포함된 영역 전체를 박스로 둘러싸세요.
    ℹ️ 이 단계는 선택 사항입니다. 해당 도면에 뷰 심볼이 없거나 검토가 불필요하면 Enter를 눌러 건너뛸 수 있습니다. 단, 영역을 지정해야 시트 2 (뷰심볼 검토)가 생성됩니다.
  5. [도면목록표]의 경우, 데이터가 나열된 단(Column)의 첫 번째 구석과 마지막 구석을 순서대로 드래그하여 지정합니다.
    ⚠️ 여러 단(Column)이 있을 경우 순서대로 반복 지정하고, 모든 단 지정이 끝나면 빈 공간에 우클릭(또는 Enter)으로 루프를 종료합니다.

Step 2  ·  자동 검토 프로그램 실행

DWGChecker.exe를 더블클릭하여 실행한 뒤 아래 항목을 입력합니다.

① 도곽 원본
도곽으로 사용된 원본 DWG 파일 (예: X-FORM.dwg)을 선택하거나 창에 끌어다 놓으세요. 도곽 블록 이름이 자동으로 채워집니다.
② 목록표 DWG
표지 쪽에 있는 도면목록표 DWG 파일을 선택하거나 창에 끌어다 놓으세요.
③ 도면 폴더
검토할 개별 도면들이 모여있는 폴더를 추가합니다. 여러 폴더를 한 번에 끌어다 놓는 것도 가능합니다.
고급 옵션
개별 도면의 도곽 블록 이름이 목록표와 다를 경우 체크박스를 켜고 별도 이름을 입력합니다.
▶️ [검토 시작 →] 버튼을 클릭하면 분석이 시작됩니다. 하단 진행 바와 로그 콘솔에서 진행 상황을 확인할 수 있으며, [⏹ 취소] 버튼으로 언제든 중단할 수 있습니다.

Step 3  ·  엑셀 리포트 확인

분석 완료 후 엑셀 폴더가 자동으로 열립니다. 도면검토리포트_최종.xlsx를 열어 결과를 확인하세요.

📊 엑셀 리포트 읽는 법

📋 시트 1 — 목록표 검토

도면목록표(LIST)와 개별 캐드 도면(DWG)을 도면번호 기준으로 대조하는 메인 시트입니다.

빨간색 칸: 불일치 항목
흰색 칸: 정상 (완전 일치)
상태 값의미
일치양쪽 데이터가 완전히 일치
DWG 누락목록표에는 있으나 CAD 파일이 없음
목록표 누락CAD 파일은 있으나 목록표에 없음
도면번호 불일치도면번호가 서로 다름
도면명 불일치도면명이 서로 다름
축척 불일치A1 또는 A3 축척이 서로 다름
동 불일치동·구역 정보가 서로 다름
도면명/축척 불일치여러 항목이 동시에 다를 경우 /로 연결하여 표시

🔍 시트 2 — 뷰심볼 검토

각 CAD 도면 내부의 뷰 기호(부분 상세도 참조 기호)를 추출하여 도면명·축척이 도곽 정보와 일치하는지 검토합니다.

빨간색 행: 불일치 또는 오류
주황색 행: 중복 감지
흰색 행: 정상
상태 값의미
일치도면명·축척 모두 일치
도면명 불일치뷰 도면명이 도곽 도면명과 맞지 않음
축척 불일치뷰 축척이 도곽 축척과 맞지 않음
도면명/축척 불일치도면명과 축척 모두 맞지 않음
중복같은 파일 내 동일 뷰 도면명이 두 번 이상 등장 (오타 의심)
ℹ️ 뷰심볼 인식 조건: 원(Circle) + 우측 수평 연장선 구조여야 합니다. 뷰 기호 탐색을 위한 view_symbol_roi가 SET_ROI에서 설정되어 있어야 합니다.

🏗️ 동(구역) 정보 자동 추출 방식

① 도면명 앞 동 이름 분리

도면명 맨 앞에 102동, A동 등 동 식별자가 있으면 구분 열로 자동 분리합니다.

102동 지하6층 평면도 → 동: 102동 / 도면명: 지하6층 평면도

② 코어·세부 구역 합산

층 정보(지하N층, 지상N층) 이전의 구역 식별자를 동 정보에 합산합니다.

102동 코어#1 지하6층 평면도 → 동: 102동 코어#1 / 도면명: 지하6층 평면도

③ 공간 들여쓰기(Spatial Indentation) 상속

동·구역 정보가 생략된 들여쓰기 행은 위 참조 행의 동 정보를 자동으로 상속합니다.

AA-300-081 102동 지하6층 평면도 → 동: 102동 AA-300-082 (들여쓰기) 지하5층 평면도 → 동: 102동 ← 자동 상속 AA-300-083 (들여쓰기) 지하4층 평면도 → 동: 102동 ← 자동 상속 AA-400-001 101동 코어#1 지하6층~지하5층 평면도 → 동: 101동 코어#1 AA-400-002 (들여쓰기) 지하4층~지하3층 평면도 → 동: 101동 코어#1 ← 자동 상속

⚠️ 자주 묻는 질문 (FAQ)

검토 시작 버튼을 눌렀는데 "엑셀 파일이 이미 켜져 있습니다"라고 떠요.
기존 도면검토리포트_최종.xlsx 파일이 열려있으면 덮어쓰기가 불가합니다. 엑셀 창을 닫고 다시 눌러주세요.
"구역 설정(JSON) 파일이 없습니다"라고 뜹니다.
입력한 '도곽 블록 이름'과 SET_ROI로 설정했던 도곽 이름이 다르면 발생합니다. 이름의 띄어쓰기, 대소문자를 정확히 확인하세요.
도면번호나 축척이 자꾸 이상하게 추출됩니다.
오토캐드에서 SET_ROI를 다시 실행하여 박스를 조금 더 넉넉하게(또는 타이트하게) 다시 지정해 보세요.
동 정보가 도면명에 같이 붙어서 나옵니다.
도면목록표에서 동 이름이 도면명 맨 앞이 아닌 중간에 위치할 경우 분리되지 않습니다. 도면목록표 원본 작성 규칙을 확인해 주세요.
개별 도면과 도면목록표의 도곽 블록 이름이 달라요.
고급 옵션 체크박스를 켜고 개별 도면에서 사용하는 도곽 블록 이름을 별도로 입력하세요. ROI 좌표 기준은 항상 도면목록표 도곽을 기준으로 적용됩니다.
개별 도면이 외부참조(XREF)가 아닌 일반 블록 도곽입니다.
일반 블록 도곽도 외부참조와 동일하게 인식됩니다. 고급 옵션에서 해당 블록 이름을 입력하면 됩니다. 도곽이 90°·270° 회전된 경우에도 자동 보정됩니다.
뷰심볼 검토 시트가 생성되지 않습니다.
SET_ROI 설정 시 view_symbol_roi 항목이 함께 저장되어 있어야 합니다. LISP 설정을 확인하고 ROI를 다시 설정해 주세요.
뷰심볼 축척 형식이 달라서 감지가 안 됩니다.
A3=1/200, A3:200, A3-1/200 등 다양한 형식을 지원합니다. 단, A1 또는 A3 텍스트가 축척 값과 함께 명시되어 있어야 합니다.
